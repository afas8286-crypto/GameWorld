# GameWorld Hub

این پروژه یک **نسخه‌ی نمایشی موبایل‌محور و قابل اجرا** از هاب GameWorld است که موارد اصلی را در یک تجربه‌ی سبک و جذاب جمع می‌کند: ۱۳ پت، Age 1–100، آرنا، ضدتکرار، اسپین روزانه، Surprise Drop، فروشگاه، کلکسیون، ماموریت، دوستان، Top 20 و بازی‌های سریع مثل Truth or Dare.

## اجرا روی GitHub Pages
- فقط فایل‌های `index.html`، `style.css` و `app.js` را در ریشه‌ی ریپو قرار بده.
- این نسخه برای static hosting آماده است.
- هیچ secret واقعی داخل فرانت‌اند قرار داده نشده است.

## اجرا با backend محلی
```bash
npm install
GAMEWORLD_OWNER_KEY="یک-کلید-قوی-محلی" npm start
```
سپس `http://localhost:3000` را باز کن.

## وضعیت واقعی این تحویل
- **واقعاً پیاده و قابل تست در مرورگر:** رابط موبایل‌محور، انتخاب ۱۳ پت، داشبورد، اسپین، Surprise Drop، خرید نمایشی، بانک نمایشی، پنجره‌های آرنا/فروشگاه/کلکسیون/دوستان/رتبه‌بندی، بازی‌های سریع، Top 20 preview و anti-repetition پایه در تاریخچه‌ی محلی.
- **اسکلت backend اضافه شده:** health، config، leaderboard، ساخت room و owner events با کلید سروری.
- **هنوز production-ready نیست:** احراز هویت کامل کاربر، دیتابیس واقعی، WebSocket چندنفره، صداهای فایل‌محور، مدل‌های واقعی 3D، اجرای کامل AI Guardian، snapshot/rollback واقعی، rate limiting و سیستم recovery باید در backend تکمیل شوند.
- **امنیت:** رمز/توکن واقعی hard-code نشده است. کلید مالک فقط از متغیر محیطی خوانده می‌شود.
